## Описание проекта
Данный проект представляет собой веб-сервер на языке Go, который выступает бэкендом для планировщика задач (TODO-листа). 
Сервер обрабатывает REST API запросы от фронтенда, хранит данные в базе данных SQLite (`scheduler.db`) и отдает статические файлы веб-интерфейса. 
В проекте реализована сложная логика вычисления следующей даты выполнения задачи (`NextDate`) на основе правил повторения (каждый день, ежегодно, в определенные дни недели или числа месяца).

## Выполненные задания со звёздочкой
Были выполнены задания со звездочкой:
1. **Полная реализация правил `NextDate`**: помимо базовых правил (`d` и `y`), реализована поддержка правил `w` (выбор дней недели) и `m` (выбор дней месяца, включая отрицательные значения для отсчета с конца месяца, и фильтрацию по месяцам).
2. **Поиск задач**: обработчик `GET /api/tasks` поддерживает параметр `search`. Поиск работает как по подстроке в заголовке и комментарии, так и по точной дате (если `search` передан в формате `DD.MM.YYYY`, например `08.02.2024`).

## Инструкция по локальному запуску
1. Перейдите в корневую директорию проекта.
2. Вы можете задать переменные окружения перед запуском, если хотите изменить настройки по умолчанию:
   * `TODO_PORT` — порт для веб-сервера (по умолчанию `7540`).
   * `TODO_DBFILE` — путь к файлу базы данных (по умолчанию `scheduler.db` в корне проекта).
3. Запустите сервер командой:
   go run .
Откройте в браузере адрес: http://localhost:7540/

Инструкция по запуску тестов
Тесты находятся в директории tests.
Важно: тесты обращаются к серверу по HTTP, поэтому перед их запуском убедитесь, что ваш веб-сервер уже запущен (в отдельном окне терминала).
В файле tests/settings.go проверьте, что выставлены следующие параметры для проверки всего реализованного функционала:
var FullNextDate = true (проверка правил w и m).
var Search = true (проверка поиска по задачам).
var Token = "" (аутентификация не используется).
Запустите тесты из корневой директории проекта:
bash
go test ./tests
